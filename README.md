# Marina Hacks 6.0 - TBYF Writing Assistant
Made by Hayden Chelstrom, Jacob Esmane, and Guy Gamble for Marina Hacks 6.0

## How to run the program
in powershell terminal "ctrl + `" type:
```bash
node server.js
```
it should run locally on http://localhost:3000 - You will know it works if the terminal says "Tofu server running at http://localhost:3000"

to close it, press "ctrl + c" in the terminal

# Note
If not running, may need to install AI dependencies
```bash
npm.cmd install @google/genai express-rate-limit
```

## Imports
- Node.js
- Express.js
- Supabase Database
- Google GenAi
